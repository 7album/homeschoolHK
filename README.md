# 家裡學 HK

供香港在家教育、或正在考慮在家教育的家長使用，尤其是幼兒階段。這個網頁是給家長社群用的靜態頁，不是教育局，也不是診所。

介面語言是繁體中文書面語。沒有建置步驟，沒有 npm，沒有外部 CDN。打開 `index.html`（或把整個資料夾放到靜態網站）就可以使用。

## 這個網頁做什麼

兩個範圍分開，不會混在同一張表。

### 1. 社區資訊（公開）

可搜尋、可用標籤篩選的資料卡。清單預設按 **↑** 支持數由高到低排序（內建、社區建議與本機自行新增的卡一併參與）。收合時每張只顯示**主題標籤**、**標題**與 **↑** 按鈕；點卡片可展開閱讀全文、年齡標籤與來源。按 **↑** 會把票數寫入共用試算表（同一張卡在本機只會記一次）。

篩選列：**年齡**籌為綠色、**主題**籌為暖色；卡片上的年齡標籤亦為綠色、主題標籤為暖色。年齡只有四個：`0–6`、`6–12`、`12–18`、`>18`。篩選時，年齡之間是「或」，年齡與主題之間是「及」。搜尋範圍包括標題、內文、主題標籤、年齡標籤及來源。

內建卡片在 `cards.json`；社區建議卡由 `cards/community-index.json` 列出檔案路徑。頁面不能改、不能刪內建卡。

訪客可以向社區清單**建議**新卡片：在「社區資訊」分頁填表後，瀏覽器會開啟 GitHub 官方「新增議題」頁面，標題與內文已填入卡片 JSON（無需本站的密鑰或帳戶整合）。請在 GitHub 按「Submit new issue」；維護者審閱並加入清單後，卡片才會對所有人顯示。議題內文會包含建議的檔案路徑 `cards/community-<短編號>.json` 及完整 JSON。

若你曾在舊版把卡片只存於這部瀏覽器，那些紀錄仍在 `localStorage`（鍵名不變），可刪除或經「家裡紀錄」匯出；新建議不再寫入瀏覽器。沒有年齡欄位的舊本機卡片仍會顯示。

### 2. 家裡紀錄（私人）

分頁列在左側的是「家裡紀錄」，右側是「社區資訊」。家裡紀錄預設開啟。

尚未有本機資料時，預設一位**小孩**稱呼「小孩」（可自行改名）。按標題列的**人形按鈕**可展開小孩設定：每位一行 **稱謂**、**出生年月**（僅年與月，可留空）、移除按鈕；改動即時寫入本機。可按「**+ 小孩**」再加一位。標題旁的 **+** 與「**記錄一項學習或活動**」會開啟同一個日記表單。

每則紀錄須選**種類**（閱讀、影音、運動、遊戲、外遊、數位、課程、其他）、**項目**（公開標題）、日期與小孩；**詳情**可留空且不公開。新紀錄會依出生年月計算至本月已滿的整歲數；若尚未設定出生年月，會沿用舊版留下的數字年齡（不會反推出生月）；兩者皆無仍可儲存。寫入或分享至試算表時會帶上該整歲數（無年齡則不帶）。舊版種類在讀取時會對應到上述新種類；舊紀錄保留已存的年齡或年齡段。

「**最近 7 日家長分享**」列出公開項目。說明為：**+1 加入你的孩子記錄；❤️以示支持！** — **+1** 把項目記入本機家裡紀錄；**❤️** 對該公開項目表示支持（計數經試算表）。下方「近期紀錄」可篩選本機全部日記。

**備份**區有三個按鈕：**匯出**、**匯入**（JSON，可合併或取代本機資料）、**同步**。同步需輸入或生成同步碼，並在確認後才上傳；只有持有相同同步碼、**同時**開着這個頁面的家長才會合併，關掉頁面就不會再上傳或補傳。

私人資料的鍵名仍是 `homeschool-hk-private-v1`。開啟頁面不會清掉已儲存的小孩或紀錄。

頁尾左側「Created with ❤️ & 🤖 by Sheph」連至本站的 [GitHub 儲存庫](https://github.com/7album/homeschoolHK)（新分頁開啟）；右側 **🙏 Wish** 可開啟意願表單。

## 私隱界線

- 公開卡片的文字在 `cards.json`，任何人打開網站都看得到。裡面沒有你的家裡學習日記。
- 家裡紀錄預設在 `localStorage`（鍵名 `homeschool-hk-private-v1`）。按「同步」並確認後，才會上傳至共用試算表供同碼、同時在線的家長合併；不會公開給其他家庭。
- 清除網站資料、無痕模式結束、更換瀏覽器或更換電話，若沒有匯出或同步，私人資料會消失。
- 社區資訊卡的 **↑** 與家長分享的 **❤️**、以及同步與部分分享功能，會呼叫現有的 Google Apps Script 端點；沒有分析或字型 CDN。來源連結要自行點開，才會離開這個網站。
- 這不是醫療建議，不是診斷工具，不是病歷系統。

## 使用方法

1. 打開網站，預設在「家裡紀錄」。要查社區資料時切到右側「社區資訊」，搜尋或點選「年齡」「主題」。
2. 想向公開清單建議一張卡，在「社區資訊」填「向社區清單建議一張資訊卡」。年齡可不選。按鈕會開啟 GitHub 新增議題頁（內文已含 JSON）；在 GitHub 提交議題。維護者加入清單後才會出現在列表。
3. 在「家裡紀錄」用人形按鈕設定小孩稱呼及出生年月（可留空）。按標題 **+** 或「記錄一項學習或活動」新增一則，選種類並填項目。
4. 在「最近 7 日家長分享」用 +1 或 ❤️；在「近期紀錄」查看本機全部日記。
5. 用「匯出」「匯入」備份 JSON；需要多位家長同時合併時用「同步」（同碼、頁面保持開啟）。

## 向社區建議資訊卡（GitHub 議題）

本站是靜態頁，**不能**在瀏覽器存放 GitHub 密鑰。建議流程完全在 GitHub 官方網頁完成：

1. 在網站表單填寫標題、摘要、可選來源網址、主題標籤（逗號分隔）、年齡（可不選）。
2. 按「在 GitHub 提交建議（開啟新增議題）」。瀏覽器會開啟 `https://github.com/7album/homeschoolHK/issues/new`，並在網址參數中預填議題標題與內文（含建議檔案路徑及卡片 JSON；需登入 GitHub 帳戶才能提交）。
3. 在 GitHub 按「Submit new issue」，等候維護者審閱。加入清單後，所有訪客都會在「社區資訊」看到該卡。

建議卡的 JSON 格式（與表單欄位一致）：

```json
{
  "id": "community-短編號",
  "title": "標題",
  "summary": "摘要",
  "url": "https://可留空字串",
  "tags": ["主題一", "主題二"],
  "ages": ["0–6", "6–12"],
  "submittedAt": "2026-10-03"
}
```

年齡只接受 `0–6`、`6–12`、`12–18`、`>18`。表單會把上述 JSON 放進議題內文的 ```json 區塊。

## 這次查不到、所以沒有寫成事實的東西

- **沒有一套公開的「在家教育登記／批准」逐步程序。** 2014 年教育局答覆只說可以寫信或電郵要求評估，沒有印專用電郵、表格、時限，也沒有說寫信就等於批准。通告第 21/2024 號講的是在學學童缺課跟進，不能把它改寫成登記流程。
- 沒有核對到《教育條例》電子版原文（e-Legislation 這次只回到載入頁）。出席令及刑罰，只按通告第 21/2024 號的註腳轉述，不當作法條全文。
- 2014 年的「25 宗」不是現時人數。
- 沒有在家教育專線。3698 4411 是通告上的缺課個案查詢電話。
- 沒有把社區網站描述的家訪次數、批准方式，寫成官方步驟。
- 「寶寶愛活動」單張「一至兩歲、每天至少 180 分鐘」那句有標明年齡範圍；超出該範圍的幼兒，頁面沒有另外編一個時數。
- 沒有一張卡只標 `>18`。夜間成人教育頁同時寫成年學員和年滿 17 歲。15 歲或以上的輟學協助，中文頁和通告都沒有寫上限；英文常見問題該題寫 “over 15”，沒有收成同一個歲數。
- homeschool.hk 與 hsa.hk 都沒有寫服務年齡。前者只按法例頁的 6 至 15 歲標 6–12 與 12–18。後者只因首頁有中學生一節而標 12–18；那位前學生的碩士句子沒有標成 >18。
