# 家裡學 HK

供香港在家教育、或正在考慮在家教育的家長使用，尤其是幼兒階段。這個網頁是給家長社群用的靜態頁，不是教育局，也不是診所。

介面語言是繁體中文書面語。沒有建置步驟，沒有 npm，沒有外部 CDN。打開 `index.html`（或把整個資料夾放到靜態網站）就可以使用。

## 這個網頁做什麼

兩個範圍分開，不會混在同一張表。

### 1. 社區資訊（公開）

可搜尋、可用標籤篩選的資料卡。預設次序按年齡：先是 0–6（幼兒、幼稚園、家庭健康服務），然後是只講小學的 6–12，然後是只講中學的 12–18，然後是同時涉及 12–18 與 >18 的夜間成人課程和 15 歲或以上輟學協助，最後是橫跨多於一個年齡的入學規定、在家教育官方說法、家長網站和學校概覽。

每張卡都有來源網址及日期，並有年齡標籤。年齡只有四個：`0–6`、`6–12`、`12–18`、`>18`。沒有「現時適用」「日後參考」或「全年齡」。篩選時，年齡之間是「或」，年齡與主題之間是「及」。搜尋範圍包括標題、內文、主題標籤、年齡標籤及來源。沒有一張卡只標 `>18`：夜間課程頁同時寫成年學員和年滿 17 歲；15 歲或以上的輟學協助沒有寫上限。

訪客可以向社區清單**建議**新卡片：在「社區資訊」分頁填表後，瀏覽器會複製 JSON 並開啟 GitHub 官方「新增檔案」頁面（無需本站的密鑰或帳戶整合）。請在該頁貼上 JSON、建立分支並開立拉取請求；維護者合併後，卡片才會對所有人顯示。每張建議卡放在獨立檔案 `cards/community-<短編號>.json`，並在 `cards/community-index.json` 的 `files` 陣列登記路徑，以免多人同時建議時改寫整份 `cards.json` 而互相覆蓋。

若你曾在舊版把卡片只存於這部瀏覽器，那些紀錄仍在 `localStorage`（鍵名不變），可刪除或經「家裡紀錄」備份匯出；新建議不再寫入瀏覽器。內建卡片寫在 `cards.json`，頁面不能改、不能刪。沒有年齡欄位的舊本機卡片仍會顯示。

### 2. 家裡紀錄（私人）

尚未有本機資料時，預設兩位小朋友：「姐姐」「妹妹」。年齡或出生備註可以改，也可以新增或移除。已儲存的小朋友名稱不會被改寫。日記欄位：日期、小朋友、**兩層日常**（先選範圍：睡眠、進食、情緒、語言、遊戲、活動、社交、其他；再點選該範圍下的具體種類，例如進食下的「正餐」「小食」等）、短句，以及可留空的程度與時長。新紀錄必須選定一種具體種類才會儲存。

舊版八個粗類別（內部代碼如 `sleep`、`eating`，或當時的口語／書面標籤如「睡眠」「瞓覺」）在**讀取時**會對應到上列具體種類之一，紀錄不會消失；顯示與統計都按對應後的種類計算。

最近 14 日先選小朋友與**一個範圍**，橫條按該範圍內各具體種類計則數，方便在同一範圍內對照。那是記下的次數，不是評估分數。

可以匯出 JSON（小朋友、紀錄、以及仍留在本機的舊版個人卡片），也可以匯入：先詢問要合併（只加入尚未存在的項目）還是取代。沒有帳戶，不會上傳。

私人資料的鍵名仍是 `homeschool-hk-private-v1`。開啟頁面不會清掉已儲存的小朋友或紀錄。

## 私隱界線

- 公開卡片的文字在 `cards.json`，任何人打開網站都看得到。裡面沒有這兩位小朋友的個人紀錄。
- 私人資料用 `localStorage`，鍵名 `homeschool-hk-private-v1`。只在這個瀏覽器。
- 清除網站資料、無痕模式結束、更換瀏覽器或更換電話，私人資料會消失。要留底就匯出。
- 頁面不會呼叫分析、字型 CDN 或其他第三方。來源連結要自行點開，才會離開這個網站。
- 這不是醫療建議，不是診斷工具，不是病歷系統。

## 使用方法

1. 打開網站，先看「社區資訊」。搜尋，或點選「年齡」「主題」。
2. 想向公開清單建議一張卡，填「向社區清單建議一張資訊卡」。年齡可不選。按鈕會複製 JSON 並開啟 GitHub；貼上內容、更新 `cards/community-index.json`、開立拉取請求。合併後才會出現在列表。
3. 轉到「家裡紀錄」。改稱呼及出生備註。記下一件日常。
4. 用「最近 14 日」選小朋友與範圍，看該範圍內哪種具體日常記得多。
5. 「匯出 JSON」下載備份。更換電話時用「匯入 JSON」。

## 向社區建議資訊卡（GitHub 拉取請求）

本站是靜態頁，**不能**在瀏覽器存放 GitHub 密鑰。建議流程完全在 GitHub 官方網頁完成：

1. 在網站表單填寫標題、摘要、可選來源網址、主題標籤（逗號分隔）、年齡（可不選）。
2. 按「在 GitHub 開立拉取請求（JSON 已複製，請貼到編輯器）」。瀏覽器會複製一個 JSON 檔內容，並開啟例如 `https://github.com/7album/homeschoolHK/new/main/cards/community-<短編號>.json` 的新增檔案頁（需登入 GitHub 帳戶才能提交）。
3. 在編輯器貼上 JSON，建立新分支，提交。
4. 另開 `cards/community-index.json`，在 `files` 陣列加入該檔路徑（例如 `"cards/community-abc123.json"`），一併提交到同一拉取請求。
5. 開立拉取請求，等候維護者審閱。合併後，所有訪客都會在「社區資訊」看到該卡。

建議卡的 JSON 格式（與表單欄位一致）：

```json
{
  "id": "community-短編號",
  "title": "標題",
  "summary": "摘要",
  "url": "https://可留空字串",
  "tags": ["主題一", "主題二"],
  "ages": ["0–6", "6–12"],
  "submittedAt": "2026-10-03"
}
```

年齡只接受 `0–6`、`6–12`、`12–18`、`>18`。GitHub 網址**不能**可靠地預填檔案內容，因此按鈕標明須自行貼上已複製的 JSON。

## 這次查不到、所以沒有寫成事實的東西

- **沒有一套公開的「在家教育登記／批准」逐步程序。** 2014 年教育局答覆只說可以寫信或電郵要求評估，沒有印專用電郵、表格、時限，也沒有說寫信就等於批准。通告第 21/2024 號講的是在學學童缺課跟進，不能把它改寫成登記流程。
- 沒有核對到《教育條例》電子版原文（e-Legislation 這次只回到載入頁）。出席令及刑罰，只按通告第 21/2024 號的註腳轉述，不當作法條全文。
- 2014 年的「25 宗」不是現時人數。
- 沒有在家教育專線。3698 4411 是通告上的缺課個案查詢電話。
- 沒有把社區網站描述的家訪次數、批准方式，寫成官方步驟。
- 「寶寶愛活動」單張「一至兩歲、每天至少 180 分鐘」那句有標明年齡範圍；超出該範圍的幼兒，頁面沒有另外編一個時數。
- 沒有一張卡只標 `>18`。夜間成人教育頁同時寫成年學員和年滿 17 歲。15 歲或以上的輟學協助，中文頁和通告都沒有寫上限；英文常見問題該題寫 “over 15”，沒有收成同一個歲數。
- homeschool.hk 與 hsa.hk 都沒有寫服務年齡。前者只按法例頁的 6 至 15 歲標 6–12 與 12–18。後者只因首頁有中學生一節而標 12–18；那位前學生的碩士句子沒有標成 >18。
